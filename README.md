# Climax™ — The premium school of pleasure

A high-end sex-education landing page. The product teaches people the art and
science of intimacy so they can become confident, masterful lovers and the
perfect partner — with expert-led, science-backed video courses.

> For adults 18+. All content is educational.

## Selling points (headline copy)

- **Become a master of intimacy** — the core promise.
- **Be unforgettable** — techniques that turn good into breathtaking.
- **Science, not myths** — grounded in real anatomy, psychology and clinical practice.
- **The perfect partner** — communication, confidence and presence.
- **Private & judgment-free** — discreet billing and encrypted streaming.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Page markup — hero, value props, course grid, method, testimonials, pricing, CTA, footer. |
| `styles.css` | Premium dark theme with pink→orange gradient accents (Fraunces + Inter type). |
| `script.js` | Course catalogue, category filters, and the Courses / All videos toggle. |

## Run locally

It's a static site — no build step.

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
